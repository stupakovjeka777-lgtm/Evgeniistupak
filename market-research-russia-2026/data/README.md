# Данные

## `raw/` — сырые данные

Кладётся как получено: выгрузки, скриншоты, сохранённые страницы. **Не редактируется.**
Это доказательная база: через полгода оффер конкурента и цены изменятся, а файл останется.

## `clean/` — обработанные данные

Таблицы, готовые к анализу. К каждому файлу — соседний `.md` или строка в шапке CSV:
из какого сырого файла получен и что с ним делали.

## Именование

```
YYYY-MM-DD_источник_суть.расширение
2026-08-31_avito_ceny-divany-msk.csv
2026-08-31_rosstat_roznichnyj-tovarooborot.xlsx
```

## Что сюда не кладём

- Персональные данные респондентов: ФИО, телефоны, адреса, переписку с контактами.
  В интервью используем роли и номера: «клиент №3, сегмент А».
- Файлы больше 50 МБ — храни вне репозитория, а здесь оставь ссылку и описание.
- Учётные данные, токены, выгрузки из личных кабинетов вместе с логинами.
