# Google Trends

**Не собрано** — доступа из рабочей среды нет.

## Зачем нужен, если есть Wordstat

Wordstat даёт абсолютную частотность, но плохо показывает **динамику**.
Google Trends нужен для одного вопроса: спрос растёт, стоит на месте или падает?

## Что снимать

| Что | Как | Порог решения |
|---|---|---|
| Динамика за 5 лет по главному запросу | trends.google.com, регион Россия | Устойчивое падение 2 года подряд — ниша в резерв |
| Динамика за 12 месяцев | То же | Уточняет сезонность из Wordstat |
| Сравнение 3–5 ниш между собой | Режим сравнения | Показывает, какая из них теряет интерес |

## Ограничение

Google Trends в России показывает **относительный** интерес и по неполной выборке
(доля Google в поиске меньше, чем у Яндекса). Использовать для направления тренда,
никогда — для оценки объёма спроса.
