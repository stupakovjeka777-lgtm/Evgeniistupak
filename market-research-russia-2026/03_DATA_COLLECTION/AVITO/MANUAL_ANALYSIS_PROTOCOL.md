# Протокол ручного анализа Авито

**Почему вручную.** Автоматический сбор из рабочей среды недоступен, а обход
технических ограничений не стоит потраченного времени. Репрезентативная выборка,
снятая руками по единому протоколу, даёт достаточную точность для отбора ниш —
при условии, что протокол одинаков для всех ниш.

**Ключевое правило:** все ниши замеряются **в один день, в одном городе, одним
способом**. Данные, снятые в разные дни, между собой несравнимы.

### Блок 3. Признаки активности

| Признак | Как проверить | Что означает |
|---|---|---|
| Скорость ответа продавцов | Написать 3 лидерам как покупатель | Медленный ответ = наша возможность |
| Есть ли продавцы с большим числом объявлений | Профили | Насколько профессионализировано поле |
| Обновляются ли объявления | Даты публикации | Живая ниша или заброшенная |
| Есть ли доставка у конкурентов | Метка Авито Доставки | Работают ли за пределами города |
| Просмотры и избранное | Если отображаются публично | Реальный интерес, а не число объявлений |

> Тест скорости ответа — самый информативный за наименьшее время.
> Три сообщения трём лидерам показывают уровень поля точнее, чем час анализа фото.

### Блок 4. География

Проверить одну и ту же нишу в 3–5 городах: Москва, СПб, миллионник, город 300–700 тыс.

| Город | Объявлений | Медиана цены | Средний балл топ-5 | Вывод |
|---|---|---|---|---|
| Москва | | | | |
| СПб | | | | |
| Миллионник | | | | |
| Средний город | | | | |

**Что ищем:** города, где спрос есть, а качественного предложения нет.
Это чаще не столицы. Разница медианных цен между городами показывает,
где выше маржа при том же поставщике.

## Сводная строка по нише

Переносится в скоринг для пересчёта критериев «слабость поля» и «устойчивость спроса».

```
Ниша: ______   Дата: ______   Город: ______
Объявлений всего / в городе: ______ / ______
Доля компаний: ______%
Новых за сутки: ______
Медиана цены: ______ ₽
Средний балл топ-10: ______
Скорость ответа лидеров: ______
ВЫВОД (заходить / осторожно / нет): ______
```

## Ограничения этого метода — фиксируем честно

1. Число объявлений **не равно спросу**. Много объявлений может означать
   и высокий спрос, и то, что никто не продаёт.
2. Выборка топ-10 смещена: выдача учитывает продвижение, а не только качество.
3. Замер — срез одного дня. Сезонные ниши требуют повторного замера.
4. Просмотры и избранное видны не всегда — при отсутствии данных писать
   **ДАННЫХ НЕДОСТАТОЧНО**, а не додумывать.

Эти ограничения не отменяют метод — они означают, что результат используется
для **сравнения ниш между собой**, а не как абсолютная оценка рынка.
