# ТОП-20 товарных гипотез для теста

Отобраны из 59 в `PRODUCT_MATRIX.csv`. **Отбор не равен сортировке по баллу** —
применено портфельное правило.

---

## Почему не просто «первые 20 по score»

Чистая сортировка даёт перекос: в верхних строках оказываются самые дорогие
позиции под заказ, причём пять из них — из одной ниши. Это не портфель,
а одна ставка, размноженная на пять объявлений.

Правила отбора:

| Правило | Зачем |
|---|---|
| Максимум 5 гипотез на нишу | Чтобы провал одной ниши не обнулил тест |
| 15 из 20 — из ТОП-3 ниш | Тест должен проверять основную стратегию, а не всё подряд |
| 5 из 20 — из резервных ниш | Дешёвая страховка: если ТОП-3 не подтвердится, будет с чем работать |
| Внутри ниши — разные ценовые уровни | Дорогая позиция проверяет маржу, дешёвая — объём спроса |
| Хотя бы одна позиция с быстрым циклом в каждой нише | Иначе тест закончится раньше первой сделки |

который конкурент не скопирует.

## Сводная логика: чем эти 20 гипотез похожи

| Признак | Сколько из 20 |
|---|---|
| Продаются без закупки товара | 20 из 20 |
| Требуют подбора, расчёта или изготовления под клиента | 18 из 20 |
| Чек выше 30 тыс ₽ | 17 из 20 |
| Маркетплейс структурно не может обслужить | 16 из 20 |
| Есть повтор или допродажа | 8 из 20 |

Два исключения по чеку (годовой комплект расходников, комплект стол+стулья)
включены намеренно: они проверяют **объём спроса и скорость цикла**,
которые на дорогих позициях не видны.

## Чего в этом списке нет и почему

| Не вошло | Причина |
|---|---|
| Картриджи и осмос под мойку | Прямая конкуренция с маркетплейсом, балл защищённости 3 |
| Заготовки под печать (футболки, кружки) | То же: МП дешевле |
| Расходка упаковки (плёнка, скотч) | Низкая маржа плюс требует складского остатка |
| Термопресс базовый | Есть на МП дешевле — проигрыш по цене без компенсации |

Все они логичны как **допродажа к основной сделке**, но бессмысленны
как точка входа: они не проверяют ни одну гипотезу стратегии.

## Ограничение

Все чеки и маржа — **ОЦЕНКА**. Закупочных цен нет: поиск поставщиков вынесен
в этап №2. Порядок величины взят по типовым наценкам категорий и служит
для сравнения гипотез между собой, **не для планирования выручки**.

Ни одна из 20 гипотез не проверена спросом. Приоритет теста определяется
после замера по формам из `../03_DATA_COLLECTION/`.
