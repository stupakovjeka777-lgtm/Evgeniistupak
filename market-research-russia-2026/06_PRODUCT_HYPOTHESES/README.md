# Товарные гипотезы

| Файл | Что |
|---|---|
| `PRODUCT_MATRIX.csv` | 59 товарных гипотез по 10 нишам ТОП-10 |
| `TOP_20_PRODUCT_HYPOTHESES.md` | 20 гипотез, отобранных для теста |
| `build_products.py` | Расчёт скоринга товаров |

## Глубина проработки распределена неравномерно — намеренно

| Ниши | Гипотез на нишу | Почему |
|---|---|---|
| ТОП-3 (N022, N055, N089) | по 12 | Именно они идут в тест первыми — нужна глубина |
| Резерв (N099) | 5 | Первый кандидат на замену |
| Остальные ТОП-10 | по 3 | Достаточно, чтобы понять, из чего ниша состоит |

ТЗ предполагало 10–30 гипотез на каждую перспективную нишу. Делать по 30 на все
десять — это 300 строк, из которых 280 никогда не дойдут до теста. Ресурс вложен
туда, где он превращается в действие; при переходе резервной ниши в работу
её матрица достраивается тогда же.

## Скоринг товара

Пять критериев вместо десяти нишевых — на уровне товара решает меньше вещей:

| Критерий | Вес |
|---|---|
| Возможность продать без закупки | 25% |
| Защищённость от маркетплейса | 25% |
| Абсолютная маржа с сделки | 20% |
| Средний чек | 15% |
| Скорость сделки | 15% |

Чеки и маржа — **ОЦЕНКА по порядку величины**, не расчёт. Источник закупочных
цен появится на этапе №2. До этого любая цифра маржи — ориентир для сортировки,
а не основание для планирования выручки.
