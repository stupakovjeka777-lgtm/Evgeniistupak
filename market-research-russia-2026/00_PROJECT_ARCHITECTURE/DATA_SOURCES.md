# Источники данных

Реестр использованных источников: `../10_SOURCES/ALL_SOURCES.csv`.
Здесь — карта того, откуда что берётся и что из этого доступно на практике.

---

## 1. Доступность источников в этом исследовании

| Источник | Что даёт | Статус в этапе №1 |
|---|---|---|
| Росстат | Розничный товарооборот, доходы, производство | Использован через поисковую выдачу |
| ЦБ РФ | Ключевая ставка, инфляция, прогноз | Использован через поисковую выдачу |
| Data Insight | Объём e-commerce, заказы, прогноз | Использован через поисковую выдачу |
| АКИТ | Объём интернет-торговли | Использован через поисковую выдачу |
| Деловые СМИ (Ъ, Forbes, CNews, New Retail) | Оперативные факты | Частично: ряд доменов недоступен |
| Материалы Авито | Категорийные тренды, доставка, тарифы | Косвенно, через отраслевые публикации |
| **Яндекс Wordstat** | **Спрос по запросам** | **НЕ ИСПОЛЬЗОВАН — требует авторизации** |
| **Google Trends** | **Динамика интереса** | **НЕ ИСПОЛЬЗОВАН — нет доступа** |
| **Авито (парсинг/выдача)** | **Число объявлений, цены, плотность** | **НЕ ИСПОЛЬЗОВАН — недоступен** |
| **WB / Ozon (выдача)** | **Число продавцов, цены, отзывы** | **НЕ ИСПОЛЬЗОВАН — недоступен** |
| vc.ru, YouTube, Telegram | Кейсы и механики | Частично, через поисковую выдачу |

Прямое открытие сайтов из этой среды блокируется сетевой политикой: доступен
только поиск, возвращающий заголовки, ссылки и краткие выжимки. Следствие:
**каждую цифру нужно перепроверить по ссылке перед использованием в решении.**
Ссылки сохранены в реестре именно для этого.

## 2. Что предприниматель собирает сам

Три блока данных нельзя получить иначе, чем руками. Формы подготовлены:

| Блок | Форма | Время |
|---|---|---|
| Спрос по запросам | `../03_DATA_COLLECTION/WORDSTAT/COLLECTION_FORM.md` | ~3 ч на 20 ниш |
| Конкуренция на Авито | `../03_DATA_COLLECTION/AVITO/MANUAL_ANALYSIS_PROTOCOL.md` | ~4 ч на 20 ниш |
| Насыщенность МП | `../03_DATA_COLLECTION/MARKETPLACES/MP_CHECK_FORM.md` | ~2 ч на 20 ниш |

Это примерно один рабочий день. Он превращает предварительный рейтинг в обоснованный.

## 3. Иерархия доверия

```
Собственный замер (свои объявления, свои лиды)
   ↑ выше всего — это факт про ваш рынок
Wordstat / выдача Авито, снятые вручную
   ↑ факт про рынок, но не про вас
Росстат, ЦБ, ФНС
   ↑ надёжно, но слишком крупный масштаб для ниши
Data Insight, АКИТ, отраслевые отчёты
   ↑ полезно для направления, методология не всегда раскрыта
Деловые СМИ
   ↑ проверять первоисточник
Блоги сервисов, «топ-30 товаров», инфобизнес
   ↑ только как список гипотез, никогда как доказательство
```

## 4. Правила работы с источником

1. Записать в `ALL_SOURCES.csv` **до** того, как цифра попала в отчёт.
2. Указать период данных отдельно от даты обращения: «выручка за 2025» ≠ «прочитано в 2026».
3. Ссылки живут недолго — важное сохранять в `03_DATA_COLLECTION/RAW/` со скриншотом.
4. Цифра из СМИ без первоисточника получает `reliability = low`.
5. Одна цифра — один источник. Два источника с разными цифрами — записываются оба,
   в тексте указывается диапазон, а не среднее.
