# Методология исследования

---

## 1. Логика работы

```
ГИПОТЕЗА → ДАННЫЕ → СКОРИНГ → ОТСЕВ → РЫНОЧНЫЙ ТЕСТ → ПОДТВЕРЖДЕНИЕ ИЛИ ОТКАЗ
```

Исследование не ищет «идеальный товар». Оно строит вероятностный фильтр: убирает
направления с заведомо плохим соотношением риска и шанса, чтобы тестовый бюджет
попал в те 3–5 гипотез, где вероятность выше.

Ни один вывод исследования не является решением о закупке. Решение о закупке
принимает только рыночный тест.

## 2. Уровни достоверности

Каждое утверждение в проекте помечается одним из четырёх статусов. Пометка обязательна.

| Пометка | Что значит | Как выглядит в тексте |
|---|---|---|
| **ДАННЫЕ** | Цифра из внешнего источника, есть ID в `10_SOURCES/ALL_SOURCES.csv` | `+5,4% (S3)` |
| **ОЦЕНКА** | Расчёт или интервал, выведенный из данных; показан способ расчёта | `~40–60 тыс ₽ (оценка: диапазон цен ПЭК-габарита)` |
| **ГИПОТЕЗА** | Экспертное суждение без данных, подлежит проверке тестом | `ГИПОТЕЗА: спрос смещается в ремонт частями` |
| **ДАННЫХ НЕДОСТАТОЧНО** | Проверить не удалось, вывод не строится | `ДАННЫХ НЕДОСТАТОЧНО` |

Отдельно: **ЭКСПЕРТНЫЙ СКОРИНГ** — баллы 0–10 в `05_SCORING`. Это структурированное
суждение по фиксированным якорям, а не измерение. Скоринг ранжирует, но не доказывает.

## 3. Источники и их вес

| Класс | Примеры | Надёжность | Как используется |
|---|---|---|---|
| Официальная статистика | Росстат, ЦБ РФ, ФНС, ЕМИСС | Высокая | Макро-рамка, база для оценок |
| Отраслевая аналитика | Data Insight, АКИТ, отраслевые отчёты | Средняя | Динамика рынков, структура |
| Данные площадок | Авито, WB, Ozon — публичные материалы | Средняя | Категорийные тренды |
| Деловые СМИ | Коммерсантъ, Forbes, RBC, отраслевые издания | Средняя | Быстрые факты, требуют первоисточника |
| Кейсы предпринимателей | vc.ru, YouTube, Telegram, форумы | Низкая | Механики и грабли, не цифры |
| Контент-маркетинг сервисов | Блоги SaaS, агентств, «топ-30 товаров» | Низкая | Только как список гипотез, не как факт |

**Правило двух источников:** цифра, влияющая на выбор ТОП-3, подтверждается вторым
независимым источником либо помечается «низкая уверенность».

**Отдельная оговорка про «топы товаров».** Статьи вида «что продавать на Авито
в 2026» — это SEO-контент сервисов, а не исследование. Они использованы только
как источник направлений для генерации 100 ниш и никогда — как доказательство спроса.
Более того: ниша, попавшая в такой публичный топ, получает **штраф** в скоринге,
потому что её уже прочитали тысячи конкурентов.

## 4. Как собирались данные по этапам

| Этап | Метод | Ограничение |
|---|---|---|
| Макро | Веб-поиск по официальной статистике и отраслевой аналитике | Первоисточники не открывались напрямую, см. `ASSUMPTIONS_AND_LIMITATIONS.md` |
| 100 ниш | Экспертная генерация по 12 доменам + сигналы из макро | Полностью ГИПОТЕЗЫ на входе |
| Фильтр 100→50 | Формальные стоп-факторы, у каждой ниши записана причина | — |
| Спрос по нишам | **Не собран автоматически.** Подготовлены формы сбора | Wordstat требует авторизации, Авито закрыт для парсинга |
| Конкуренция на Авито | **Не собрана автоматически.** Подготовлен протокол ручного замера | То же |
| Скоринг | Экспертные баллы по якорям + структурные критерии | Не измерение |
| Товарные гипотезы | Декомпозиция ниш с учётом ограничений модели | ГИПОТЕЗЫ |
| План теста | Дизайн эксперимента с заранее заданными стоп-правилами | — |

## 5. Что делать с непокрытым спросом

Скоринг ранжирует ниши по **структурным** признакам: защищённость от маркетплейсов,
тестируемость без закупки, абсолютная маржа с сделки, цикл сделки, логистика.
Эти признаки определяются природой товара и не требуют Wordstat.

Спрос — единственный блок, который нельзя вывести из структуры. Поэтому он
не подменяется выдуманными цифрами, а выносится в первый шаг практической работы:
`03_DATA_COLLECTION/WORDSTAT/COLLECTION_FORM.md` и
`03_DATA_COLLECTION/AVITO/MANUAL_ANALYSIS_PROTOCOL.md`.

Порядок: скоринг даёт ТОП-20 → по ним за 1–2 дня руками снимается спрос и плотность
конкуренции → скоринг пересчитывается → только после этого ТОП-3 считается финальным.

Текущий ТОП-3 в отчёте помечен как **предварительный до замера спроса**.

## 6. Принципы, защищающие от типовых ошибок

| Ошибка | Защита в методологии |
|---|---|
| Путать рост рынка с ростом товара | Рост категории не даёт баллов; баллы даёт устойчивость спроса на конкретный товар |
| Выбрать товар потому что популярный | Популярность в публичных топах = штраф, а не плюс |
| Принять свой интерес за спрос | Решение принимает только тест с заранее записанным стоп-правилом |
| Подогнать данные под желаемый вывод | Стоп-факторы формальные, применяются до скоринга |
| Влюбиться в гипотезу | В `07_.../HYPOTHESIS_LOG.md` критерий провала пишется до запуска |
| Спутать маржу % и маржу ₽ | Скоринг считает абсолютную маржу с сделки: при 20 сделках в месяц % не кормит |
| Забыть про Авито-специфику | Отдельный критерий «защищённость от маркетплейса» с весом 15% |
