# Гипотезы

Гипотеза формулируется так, чтобы её можно было опровергнуть. «Рынок большой» — не гипотеза.
«Ёмкость сегмента в Москве больше 500 млн ₽ в год» — гипотеза.

## Шаблон

```
### H1. Формулировка

- **Почему думаем так:** источник предположения
- **Как проверяем:** конкретный способ и данные
- **Подтверждается, если:** измеримый критерий
- **Опровергается, если:** измеримый критерий
- **Критичность:** блокирующая / важная / второстепенная
- **Статус:** не проверена / подтверждена / опровергнута / частично
- **Результат:** заполняется после проверки, со ссылкой на файл с данными
```
