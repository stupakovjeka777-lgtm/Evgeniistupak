# Методика рыночного теста

**Принцип:** тест не должен требовать закупки товара. Закупка — это результат
подтверждённого спроса, а не способ его проверить.

---

## 1. Четыре модели теста

### Модель A. Агентская

```
Поставщик → каталог и фото → объявление на Авито → заявка
→ передача поставщику → комиссия
```

| | |
|---|---|
| Вложения в товар | 0 ₽ |
| Что нужно | Договорённость с поставщиком + разрешение на использование его фото |
| Когда применять | Высокий чек, сложный монтаж, длинный цикл (кухни, оснащение под ключ, мезонины) |
| Риск | Поставщик может обойти вас после первого контакта |
| Как снизить | Первый контакт с клиентом только через вас; передача — на этапе замера, не раньше |

### Модель B. Продажа под заказ

```
Объявление → заявка → счёт клиенту → предоплата
→ закупка у поставщика → отгрузка клиенту
```

| | |
|---|---|
| Вложения в товар | 0 ₽ (закупка из денег клиента) |
| Что нужно | Поставщик, готовый отгружать штучно; честный срок в объявлении |
| Когда применять | Основная модель для большинства гипотез |
| Риск | Срыв срока поставщиком бьёт по вам |
| Как снизить | Два поставщика на позицию; срок клиенту с запасом в неделю |

### Модель C. Предзаказ

```
Объявление с датой поставки → сбор заявок и предоплат
→ партия у поставщика → отгрузка
```

| | |
|---|---|
| Вложения в товар | 0 ₽ |
| Когда применять | Сезонные позиции, где партия даёт лучшую цену |
| Риск | Не набралась партия — возврат предоплат |
| Как снизить | Заранее говорить о дате; возврат по первому требованию, без споров |

### Модель D. Минимальная тестовая закупка

| | |
|---|---|
| Вложения | 10–30 тыс ₽ |
| Когда применять | Только когда без образца продать нельзя, и **только после того**, как модели A–C не сработали |
| Правило | Закупается **ликвидная** позиция, которую можно продать даже при провале гипотезы |

**Приоритет: B → A → C → D.** Модель D — последнее средство, а не первое.

---

## 2. Правила теста

| Правило | Почему |
|---|---|
| Критерий успеха пишется **до** запуска | Иначе результат подгоняется под желание |
| Одна гипотеза = одно объявление в одном городе | Иначе непонятно, что сработало |
| Не запускать больше 3–5 гипотез одновременно | Больше — не хватит внимания на диалоги, и все дадут плохой результат |
| Тест длится минимум 10–14 дней | Меньше — попадание в случайную неделю |
| Отвечать на обращение в течение 15 минут в рабочее время | Скорость ответа — половина конверсии на Авито |
| Не менять объявление в первые 7 дней | Иначе неизвестно, что именно измерили |
| Фиксировать каждый диалог | Формулировки клиентов — главный побочный продукт теста |

## 3. Структура тестового объявления

Отработанная схема (подтверждается разборами кейсов, S13):

```
ЗАГОЛОВОК     Товар + ключевая выгода или проблема
              «Диван по вашим размерам — если стандартный не встаёт»

ПЕРВЫЙ ЭКРАН  Что вы решаете, а не что продаёте
              Формулировка боли клиента дословно

БЛОК ДОВЕРИЯ  Кто вы, как работаете, что с гарантией
              Фото реальных работ, а не каталожные рендеры

КОНКРЕТИКА    Сроки, цена или вилка, что входит в цену
              Отдельно: что НЕ входит (это снимает половину конфликтов)

ДЕЙСТВИЕ      Что сделать прямо сейчас
              «Пришлите размеры проёма — посчитаю за час»
```

**Ключевой приём:** целевым действием делается не «купить», а то, что клиент
может сделать бесплатно и сразу — прислать размеры, анализ воды, план зала,
модель техники. Это одновременно поднимает конверсию и квалифицирует лид.

## 4. Что считать целевым действием

| Ниша | Целевое действие |
|---|---|
| Водоочистка | Присланный анализ воды или описание проблемы |
| Мебель HoReCa | Присланный план зала или запрос сметы |
| Сублимация | Вопрос «что нужно, чтобы начать» |
| Навесное для спецтехники | Обращение с моделью техники |
| Стеллажи | Присланные размеры помещения |

Обращение без квалифицирующей информации («сколько стоит?») целевым **не считается**.
Это отсекает шум и делает цифры теста честными.

## 5. Порядок запуска

```
День 0    Замер спроса (Wordstat) → отсев ниш ниже порога
День 1    Замер поля на Авито по прошедшим нишам
День 2    Договорённость с поставщиками: отгрузка под заказ + ГАРАНТИЯ ПИСЬМЕННО
День 3-4  Сборка 3-5 объявлений, фото и тексты
День 5    Публикация. Дальше объявления не трогаются 7 дней
День 5-19 Ведение диалогов, фиксация в HYPOTHESIS_LOG.md
День 19   Сверка с заранее записанными критериями. Решение по каждой гипотезе
```

## 6. Три ошибки, которые убивают тест

1. **Тест без стоп-правила.** Гипотеза живёт вечно, потому что «ещё чуть-чуть».
   Лечится тем, что критерий провала записан до запуска.
2. **Тест на всём сразу.** Пять ниш по три объявления — это 15 диалогов в день,
   на которые не хватит времени, и все конвертят плохо.
3. **Подмена спроса вниманием.** Просмотры и избранное — не спрос. Спрос — это
   квалифицированное обращение, а лучше предоплата.
