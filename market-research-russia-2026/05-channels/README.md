# Каналы

## Что должно получиться

Ранжированный список каналов: где есть наш платящий клиент, сколько стоит его оттуда достать
и с какого канала начинаем.

## Каналы к проверке (РФ)

| Канал | Когда имеет смысл | Что проверить в первую очередь |
|---|---|---|
| Авито | Спрос уже сформирован, клиент ищет сам | Число объявлений в категории, цены в топе, скорость ответа конкурентов |
| Яндекс.Директ / поиск | Есть частотные коммерческие запросы | Частотность, цена клика, кто выкупает топ |
| Маркетплейсы (WB, Ozon) | Товар стандартизирован, влезает в логистику | Комиссии, логистика, выручка топ-карточек, возвраты |
| Telegram | Ниша с сообществом, повторные покупки | Тематические каналы, цена размещения, качество аудитории |
| VK | Локальный и визуальный спрос | Группы по городам, цена лида |
| Сарафан / рекомендации | Высокий чек, доверие решает | Доля повторных, готовность рекомендовать |
| Офлайн, партнёры, B2B | Длинный цикл, крупный чек | Кто уже держит нашего клиента и может привести |

## Правила

- Один канал проверяется одной небольшой ставкой с заранее записанным критерием успеха.
  Критерий пишется **до** запуска, иначе результат подгонится под желаемое.
- Канал сравнивается по стоимости **оплаченного заказа**, не по цене клика или лида.
- Не запускай три канала сразу: не поймёшь, что сработало.
