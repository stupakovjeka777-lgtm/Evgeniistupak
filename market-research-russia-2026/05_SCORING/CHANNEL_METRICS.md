# Метрики канала: пять новых показателей

Все пять считаются **только по данным интервью**. Desk research в них не входит.
Пока контактов нет — все значения не рассчитаны, а не равны нулю по умолчанию.

Форма сбора: `../03_DATA_COLLECTION/CUSTOMER_DISCOVERY/CONTACT_PLAN_70.csv`.

## 1. DISCOVERY CHANNEL SHARE

```
DCS(канал) = число респондентов, назвавших канал в вопросах 2 или 8
           / число содержательных контактов
```

Считается **по каждому каналу отдельно**, суммарно может превышать 100%:
респондент называет несколько источников.

| Канал | Считать по | Статус |
|---|---|---|
| Авито | вопросы 2, 8, 9 | не рассчитан |
| Поисковая выдача | вопросы 2, 8 | не рассчитан |
| Отраслевые каталоги | вопросы 2, 8 | не рассчитан |
| Маркетплейсы | вопросы 2, 8 | не рассчитан |
| Выставки | вопросы 2, 8 | не рассчитан |
| Рекомендации | вопросы 2, 8 | не рассчитан |
| Telegram и сообщества | вопросы 2, 8 | не рассчитан |
| Прямой поиск производителя | вопросы 2, 8 | не рассчитан |

## 2. PURCHASE CHANNEL SHARE

```
PCS(канал) = число респондентов, реально купивших через канал (вопрос 3)
           / число содержательных контактов
```

**Разница DCS − PCS по Авито — ключевая цифра этапа.**

| Соотношение | Что означает |
|---|---|
| DCS высокий, PCS высокий | Авито — полноценный канал: и находят, и покупают |
| **DCS высокий, PCS низкий** | **Авито работает как витрина: находят там, покупают напрямую. Для нас это успех — лид получен** |
| DCS низкий, PCS низкий | Канал не работает в этой нише |
| DCS низкий, PCS высокий | Приходят по рекомендации, Авито — только оформление сделки |

Второй случай — самый вероятный для B2B и его нельзя считать провалом.
Именно поэтому вопросы 2 и 3 разнесены.

## 3. AVITO REAL USAGE SCORE

Три **разных** сигнала, которые нельзя смешивать:

| Уровень | Источник | Что означает |
|---|---|---|
| **Знают** | косвенно из разговора | Ничего не означает: Авито знают все |
| **Используют для поиска** | вопрос 9 («да, регулярно» или «да, иногда») | Канал доходит до покупателя |
| **Покупают** | вопрос 10 (факт покупки с суммой) | Канал доводит до сделки |

```
ARU = 0,2 × доля «знают»
    + 0,3 × доля «используют для поиска»
    + 0,5 × доля «покупали»
```

Половина веса — на факт покупки. «Смотрел, но не покупал» — отдельный ответ
в вопросе 9 именно для того, чтобы не засчитать просмотр за использование.

**Статус: не рассчитан.**

## 4. SUPPLIER SWITCHABILITY SCORE

Насколько легко клиент меняет поставщика. Считается по вопросам 5, 6, 7.

| Балл | Что услышали |
|---|---|
| 9–10 | Меняли поставщика за последний год, назвали причину |
| 7–8 | Есть конкретный триггер смены, готовы рассматривать |
| 5–6 | Недовольство есть, но терпят |
| 3–4 | Работают долго, менять не планируют |
| 0–2 | Долгосрочный контракт, смена — процедура |

**Ключ — вопрос 7.** Если респондент не может назвать ни одного условия,
при котором начнёт искать нового поставщика, вход в нишу закрыт
независимо от качества рынка.

**Статус: не рассчитан.**

---

## 5. NEW SUPPLIER ENTRY SCORE

Насколько реально новому продавцу получить **первую** сделку.
Считается по вопросам 7 и 11.

| Балл | Признак |
|---|---|
| 9–10 | Названы условия входа, которые мы можем выполнить сразу (наличие, скорость, малая партия) |
| 7–8 | Условия выполнимы, но требуют подготовки (ассортимент, отсрочка) |
| 5–6 | Условия выполнимы частично |
| 3–4 | Требуется то, чего у нас нет: склад, история, сертификация |
| 0–2 | Вход закрыт: только по рекомендации или тендеру |

**Практический смысл.** Ниша с отличным рынком и NSE = 3 непригодна
для нового продавца — как бы хорош ни был товар.

**Статус: не рассчитан.**

## Как метрики меняют решение

| Комбинация | Вывод |
|---|---|
| ARU высокий + NSE высокий | **Связка работает.** Ниша готова к тесту |
| ARU высокий + NSE низкий | Канал есть, но вход закрыт: нужен другой оффер |
| **ARU низкий + NSE высокий** | **Рынок доступен, но не через Авито.** Менять канал, а не нишу |
| ARU низкий + NSE низкий | KILL |

Третья строка — та, ради которой затеян весь этап. Она означает
**«перспективный товар + другой канал»**, а не «неперспективный товар».
