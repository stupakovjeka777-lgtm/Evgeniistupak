# Источники

`sources.csv` — единственный реестр ссылок. Любая цифра в исследовании ссылается сюда по `id`.

## Колонки

| Колонка | Что писать |
|---|---|
| `id` | S1, S2, ... — по порядку, не переиспользовать |
| `title` | Название материала |
| `publisher` | Кто опубликовал |
| `url` | Ссылка |
| `type` | official / industry / media / competitor / own_data / expert |
| `data_period` | К какому периоду относятся данные (2025, 2024-Q3) |
| `accessed_at` | Дата обращения (YYYY-MM-DD) |
| `reliability` | high / medium / low |
| `local_copy` | Путь к сохранённой копии в `data/raw/`, если есть |
| `used_in` | Файлы, где использован |
| `notes` | Оговорки, методология, что источник НЕ покрывает |

## Как оценивать надёжность

- **high** — госстатистика, отчётность компаний, собственные измеренные данные.
- **medium** — отраслевые ассоциации, аналитика с описанной методологией.
- **low** — СМИ без первоисточника, пресс-релизы, «исследования» от продавцов услуг,
  экспертные мнения без данных.

Ссылки живут недолго. Для всего, что важно, сохраняй локальную копию или скриншот
в `data/raw/` и указывай путь в `local_copy`.
